# B站学习模式守护（Edge 扩展）

用于学习场景的反分心扩展，支持关键词规则、封面隐藏、AI辅助判定、时段策略、密码保护。

## 功能结构

- 首页（插件弹窗）只放功能开关（解耦）
  - 视频拦截
  - 封面隐藏
  - AI判定
  - 自动不感兴趣
  - 时段策略
  - 专注密码锁
- 详细设置页用于配置关键词、AI参数、时段规则、密码

## 核心规则

1. 黑名单优先：先命中屏蔽关键词就拦截
2. 再看学习关键词：未命中屏蔽词时再判断学习词
3. 可选封面隐藏：开启后才在首页/推荐/搜索隐藏视频卡片
4. 可选AI判定：可在无标签等场景辅助判断娱乐向内容

## 新增能力

### 1) 自动“不感兴趣”养号（默认关闭）

- 开启后，对被隐藏或被拦截视频做“内容不感兴趣”的最佳努力操作
- 因B站页面结构会变动，属于尽力执行，不保证100%成功

### 2) 时段策略（默认关闭）

- 可自定义多个时间段
- 每个时间段可选策略：
  - 普通模式（按全局规则）
  - 自定义模式（在特定时间段使用专用的拦截、封面隐藏和AI等选项）
  - 严格模式（更严格判定无标签不放行、极强AI审核）
  - 完全禁止访问

### 3) 专注密码锁（默认关闭）

- 任何会降低专注度的操作（如关闭某些关键功能、放宽规则）都需密码
- 提醒：密码最好由他人设置且不告知本人

## 目录

- `manifest.json`：扩展配置（MV3）
- `background.js`：规则判定、AI请求、时段策略、密码锁校验
- `content.js`：页面拦截层、封面隐藏、自动不感兴趣（最佳努力）
- `popup.html` + `popup.js`：首页开关
- `options.html` + `options.js`：详细设置页

## 安装

1. 打开 `edge://extensions/`
2. 开启“开发人员模式”
3. 点击“加载解压缩的扩展”
4. 选择目录：`d:\桌面\Bilibili_study_mode`

## 兼容范围

- `www.bilibili.com`
- `search.bilibili.com`

- 需自行提供可用的兼容接口（默认按 `chat/completions` 请求格式发送）
- 需填写：API URL / API Key / Model
